# Java Number Problems

A collection of Java programs that I am solving to practice number-based problems, Java fundamentals, and logical problem-solving.

This repository is part of my Java practice journey. I am solving problems step by step to improve my programming logic and strengthen my understanding of core Java concepts.

## About

The programs in this repository focus mainly on problems involving:
- Numbers and Digits
- Arithmetic operations
- Conditional statements
- Loops and Methods
- Type conversion and basic problem-solving logic

Each problem is implemented as a separate Java program.
